# 🚀 Rocket Shooter (Greenfoot)

A 2D space shooter built with Java and Greenfoot.

## Features
- Rocket follows the mouse and fires lasers automatically
- Enemies spawn randomly and get faster each level
- Explosion effect with random debris particles
- Score counter: destroy 50 enemies to win and move to the next level
- Game over when the rocket collides with an enemy

## How to run
1. Install [Greenfoot](https://www.greenfoot.org/download)
2. Open `project.greenfoot`
3. Click **Run**
